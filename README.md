# Business Sales Analytics & Customer Risk Dashboard

A business analytics project built using Python, Pandas, Jupyter Notebook, and Microsoft Power BI to analyze customer behavior, estimated revenue, customer risk, and fraud indicators.

---

## 📊 Dashboard Preview

![Business Sales Analytics Dashboard](images/Screenshot%202026-09-23%20174841.png)

---

## 🎯 Project Objective

The objective of this project is to transform raw customer data into meaningful business insights through data cleaning, exploratory data analysis, feature engineering, customer risk segmentation, and Power BI visualization.

The project focuses on understanding:

- Customer behavior
- Sales performance
- Estimated revenue
- Customer churn risk
- Fraud indicators
- Revenue distribution across countries, age groups, and categories
